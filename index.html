YouTube API anahtarı

Arama için senin kendi ücretsiz anahtarın gerekiyor. Anahtar yalnızca bu cihazın tarayıcısında saklanır.

  1. console.cloud.google.com adresinde yeni proje oluştur.
  2. "YouTube Data API v3" servisini etkinleştir.
  3. Kimlik bilgileri bölümünden API anahtarı oluştur.
  4. Anahtarı sitenin adresiyle sınırla (HTTP yönlendiren) ve yalnızca YouTube Data API v3'e izin ver.
